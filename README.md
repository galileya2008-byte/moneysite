# Сайты на ИИ — лендинг программы

Статический сайт на **HTML**, **CSS** и **JavaScript** без сборки: приветственная страница и полный продающий лендинг курса.

## Структура

| Файл | Назначение |
|------|------------|
| `index.html` | Приветственный мини-лендинг: о программе, быстрый переход к тарифам, выбор цели (сохраняется в браузере). |
| `course.html` | Полная страница программы, тарифы, FAQ, заявка. |
| `styles.css` | Общие стили и адаптивная вёрстка. |
| `app.js` | Плавное появление блоков, мобильное меню на странице курса, подсказка по выбранной цели, ссылка оплаты. |

## Локальный запуск

Из папки проекта:

```bash
npm start
```

Откроется браузер на `http://127.0.0.1:5173/index.html`. Без установки зависимостей используется `npx http-server`.

Альтернатива: откройте `index.html` в браузере напрямую (якоря и часть сценариев работают; для проверки меню и путей лучше использовать сервер).

## Настройка оплаты

Ссылки на оплату заданы в `course.html` на кнопках тарифов и в блоке «Оставьте заявку»: тариф «Для себя» — [neirogalina.ru/page247](https://neirogalina.ru/page247), «Для себя и на заказ» — [neirogalina.ru/page248](https://neirogalina.ru/page248). При смене URL замените `href` у соответствующих ссылок.

## Git

Репозиторий можно инициализировать командой `git init` в корне проекта и коммитить файлы без `node_modules` (папка указана в `.gitignore`).
